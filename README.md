# MCZ Maestro integration for Home Assistant

This a _custom component_ for [Home Assistant](https://www.home-assistant.io/).
The `mczmaestro` integration allows you to control your MCZ Maestro compatible stove on its local Wi-Fi connection (default on 192.168.120.1:81).

## Installation

### Marketplace

[![Open your Home Assistant instance and open this repository in the Marketplace.](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=Aohzan&repository=hass-mcz-maestro&category=integration)

Settings > Marketplace > Add from link > `Aohzan/hass-mcz-maestro` > Add, then Install.

Before Home Assistant 2026.11, install it through HACS the same way.

### Manually

Copy the `custom_components/mczmaestro` folder into the config folder.

## Configuration

[![Open your Home Assistant instance and start setting up a new integration.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=mczmaestro)

Or go to Settings > Devices & services > Add integration and select MCZ Maestro.
